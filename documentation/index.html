Apex Next.js Portfolio Template

Thank you for purchasing Apex! This documentation provides step-by-step instructions for installing, configuring, customizing, and deploying your new developer portfolio.

Template Highlights

  • Modern App Router: Built natively on Next.js 15 and React 19.
  • Type-Safe Architecture: Written in clean, strict TypeScript.
  • Zero Hardcoded Personal Data: All profile info, skills, projects, and contact data are controlled from a single configuration file (src/config/site.ts).
  • Built-in 10-Color Theme Switcher: Instant theme switcher with client persistence.
  • Interactive Lightbox: Keyboard-navigable image gallery for portfolio items.
  • Working Contact Form: Ready for instant EmailJS integration.

2. Prerequisites & System Requirements

Before installing the template, ensure you have the following installed on your machine:

  • Node.js: v18.18.0 or newer (v20+ recommended). Check with node -v.
  • npm: v9.0.0 or newer. Check with npm -v (or use yarn / pnpm).
  • Code Editor: Visual Studio Code or any modern code editor.

3. Installation & Setup

Follow these quick steps to get the template running locally:

  1. Unzip the downloaded package to your preferred working directory.
  2. Open your command line / terminal inside the project folder: 
    npm install
  3. Run the local development server: 
    npm run dev
  4. Open your browser and navigate to: 
    http://localhost:3000
Tip: If you plan to deploy directly, run npm run build to verify that the static compilation passes cleanly.

5. Central Configuration (site.ts)

You do not need to edit individual JSX/TSX files to update your personal details! Simply open:

src/config/site.ts

What you can customize in site.ts:

Property Description
name & role Your display name and professional title.
shortBio Introduction paragraph displayed on the homepage.
avatar Path to your portrait image in public/assets/images/.
personalInfo First name, last name, age, nationality, phone, email, address, etc.
stats Array of counter statistics (e.g. Years of Experience, Completed Projects).
skills Array of technical skills, badges, and accent colors.
experience & education Timeline blocks for your career and degrees.
projects Array of portfolio items (title, tags, category, URL, cover image, gallery).
whatsapp Phone number and pre-filled message for the floating WhatsApp button.

6. EmailJS Contact Form Setup

The contact form connects to EmailJS for serverless email forwarding:

  1. Create a free account at EmailJS.com.
  2. Add an Email Service (e.g., Gmail, Outlook) and copy your Service ID.
  3. Create an Email Template and note your Template ID.
  4. Navigate to Account > API Keys and copy your Public Key.
  5. Create a file named .env.local in the project root: 
    NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id_here
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id_here
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key_here

If no keys are provided, the form runs in safe Demo Mode and displays a friendly confirmation toast without throwing errors.

7. Style & Color Customization

The template comes with 10 pre-configured color schemes:

yellow, green, orange, blue, red, purple, goldenrod, magenta, yellowgreen, blueviolet.

To change the default accent color on initial load, modify line 40 in src/components/switch/Switcher.tsx:

const color: ThemeColor = THEME_COLORS.includes(saved as ThemeColor) ? (saved as ThemeColor) : 'yellow';

8. Deployment Guide

Deploying to Vercel (Recommended)

  1. Push your project to a GitHub, GitLab, or Bitbucket repository.
  2. Go to Vercel.com and import your repository.
  3. Under Environment Variables, optionally add your EmailJS keys.
  4. Click Deploy. Vercel will automatically build and deploy your Next.js application with zero configuration!

Static Export / Node.js Server

npm run build
npm run start
